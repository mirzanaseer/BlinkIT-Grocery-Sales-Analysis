# BlinkIT Grocery Sales Analysis

## Project Overview
This project analyzes BlinkIT grocery sales data to identify
sales trends, top-performing product categories, and outlet
performance.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Objectives
1. Identify the best-selling product categories.
2. Compare sales across outlet types.
3. Analyze relationships between product characteristics and sales.
4. Compare high-performing and low-performing products and outlets.
5. Recommend strategies to improve business performance.

## Key Findings
- Fruits and Vegetables generated the highest category sales.
- Supermarket Type1 generated the highest sales among outlet types.
- Product visibility, weight, and ratings showed very weak
  linear correlations with sales.

## Conclusion
This analysis provides insights to support inventory planning,
sales improvement, and better business decisions.
